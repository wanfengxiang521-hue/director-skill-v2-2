# 表演导演

## 表演单位

好表演是压力下为目标采取行动，不是展示情绪。每个在场人物先确定：

- `objective`：此刻想从具体对象那里得到什么，用可行动动词表达。
- `obstacle`：外部阻挡与内部禁忌。
- `stakes`：失败会失去什么。
- `tactic`：当前策略，如逼迫、讨好、拖延、试探、转移、隐瞒、示弱。
- `trigger`：什么新信息或反应使策略失效。
- `state_inertia`：上一节拍留下的身体、呼吸、注意力和关系状态。
- `subtext_gap`：说出口的内容与真实目标之间的矛盾。

节拍只有在策略失败、新信息到来、目标变化或权力转移时切换；不得为了增加细节机械规定节拍数量。

## 可观察表演链

按以下顺序设计，不直接命名结果情绪：

`触发 → 评估 → 抵抗/掩饰 → 策略行动 → 非自愿泄漏 → 新状态残留`

- 反应可以在对方话没说完时开始，但不能抢掉关键信息。
- 台词前的停顿必须是选择；台词后的停顿必须是评估或拒绝。
- 身体动作不能重复台词含义，应当先于、违背或替代语言。
- 人物要有一项正在做的具体事务；事务被打断时才形成强调。
- 强烈事件之后状态不得瞬间归零，残留要进入下一镜。
- 主角近景尽量同时承载两种真实倾向，例如帮助又怨恨、道歉又防御。

## 身体、距离与地位

为每场确定重心、动作经济性、身体开放度、呼吸和人物距离。距离改变就是关系或策略改变，不是随意走位。地位通过占据空间、移动速度、回答延迟、是否触碰他人物品、是否请求许可表现；优先寻找地位短暂破裂，而不是固定“强者不动、弱者乱动”的刻板答案。

## 达人口播表现力

“表现力强”必须成为可听、可见且与句义同步的表演谱，不得作为抽象形容词交付。逐句指定：起句状态、关键词重音、语速的加速/减速点、音高或音量变化、选择性停顿、换气位置、眼神落点、眉眼反应、头部幅度、手势起止和说完后的状态残留。表演变化跟随句义转折，不得全程高音量、每词重读、持续瞪眼、机械点头或用手势逐字翻译台词。

## 坏表演诊断

| 症状 | 原因 | 导演修复 |
|---|---|---|
| 一上来就哭或愤怒 | 在演结果 | 回到目标、抵抗和触发 |
| 等对方说完才启动 | 没有倾听 | 指定理解发生在哪个词或动作 |
| 全场一种语气 | 策略不变 | 只在策略失败处建立新节拍 |
| 手势解释台词 | 身体没有独立任务 | 给手具体事务，或取消手势 |
| 停顿空洞 | 没有内部行动 | 写评估、决定或拒绝，否则剪掉 |
| 强烈事件后恢复正常 | 忽略状态惯性 | 把残留写入下一节拍 `state_in` |
| 群体同步反应 | 群体被当成一个人 | 按信息到达顺序形成反应波 |
| 近景动作过多 | 用动作证明情绪 | 缩小到注意力、呼吸或一次策略变化 |
