# 连续性与导演 QC

## 连续性状态

逐镜记录而不是凭感觉继承：人物身份与身体状态、服装、发型、道具归属和位置、场景布局、轴线、画面方向、视线、主光方向、时间/天气、动作完成度、对白完成度、声音底床和摄影机运动相位。

上一镜 `END` 是下一镜 `START` 的候选事实；如果有意改变，必须在剧本事件或镜头间转场中说明原因。

## 相邻镜头检查

- 人物位置和视线是否让观众建立同一空间。
- 运动方向是否延续，或是否通过中性镜头明确重置。
- 道具是否仍由同一人持有、处于同一开合/湿润/损坏状态。
- 服装、发型、皮肤状态和环境天气是否无意重置。
- 光源方向和曝光变化是否有物理原因。
- 台词和动作是否重复、提前或遗漏。
- A 的结束构图与 B 的开始构图是否支持设计的切点。

## 导演 QC 门

1. **剧情完整**：逐项对照 `SCRIPT_LOCK`，导演没有改剧情。
2. **表演真实**：人物行为可追溯到目标、策略、触发或状态惯性；无人意象镜检查视觉关系。
3. **空间清楚**：人物、威胁、出口、视线和权力位置可读。
4. **镜头有因**：每个机位、运动和切点都有观众信息或情绪理由。
5. **时长可执行**：逐镜 `planned_duration >= T_min`，总和与目标一致。
6. **生成可拆**：生成单元有明确起止且服从锁定镜头；不强制复杂事件切镜。
7. **锚点可记**：每镜至少一个主视觉锚点，能说明其叙事意义、进入时机、变化过程与可冻结终态；锚点不得与其他细节争抢主注意力。

## 失败码

| 码 | 失败 | 回到哪里修 |
|---|---|---|
| D1 | 剧情事实被修改 | `SCRIPT_LOCK` |
| D2 | 行为没有人物策略 | 表演节拍 |
| D3 | 摄影机无运动动机或终点 | 镜头设计 |
| D4 | 空间方向/视线断裂 | 调度与连续性 |
| D5 | 对白、动作、摄影和声音超载 | 多轨时长 |
| D6 | 生成单元没有明确结束状态 | 生成拆分 |
| D7 | 声音与画面缺乏明确的同步或有意对位关系 | 声音方案 |
| D8 | 氛围/意象未说明具体体验和全片作用 | 戏剧功能 |
| D10 | 对外导演方案漏机位、构图、运动或焦点 | 摄影交付 |
| D11 | 隐喻没有对应关系或主要误读未处理 | 表达设计 |
| D9 | 没有视觉锚点，或锚点只是无功能装饰 | 视觉锚点合同与镜头设计 |

修复后重新生成完整 `DIRECTOR_LOCK` 版本号；不得在下游提示词里临时补救导演错误。
