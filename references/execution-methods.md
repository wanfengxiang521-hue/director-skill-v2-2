# 导演执行增强

沿用原视觉表达、表演、时长与连续性参考，以下补足制作执行。

- 表演路线→信息站点→摄影路径；先明确接触和反应，再设计焦段与运镜。预演可被身体、材质和空间实测否决。
- 不可见或后期对象提供尺度、眼线、接触与光线反馈；反应写触发、延迟、动作和恢复。
- 光学选择必须改善观看关系或材质任务。用真实肤色、包装标签、高光与运动检验，浅景深不能遮掉关键证明。
- 手—产品、脚—地面、重量—身体等接触真值优先实拍或可靠参照；数字扩展不穿过关键证据区域。
- 按表达需要分配建立、变化/延续和收束时间，感官或意象镜不强制人物反应。没有新信息时可固定摄影机，让产品、光或人完成变化。
- 痛点强度按简报与真实素材决定；用比例参照说明可见后果，不自动放大焦虑，也不把真实误解为只能少量、轻微。

Hermes每日学习中的接缝句柄、声音证明轨、微偏差密度与跨模型收益仍是候选。采用时明确是设计假设，通过具体样片测试，不作为保证或固定秒数公式。
