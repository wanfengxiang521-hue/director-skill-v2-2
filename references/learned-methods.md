# 学习方法如何进入导演决定

需要查方法依据或判断迁移边界时读取。本页为既有研究的编辑整合；外链用于追溯原资料，不代表每次调用重新验证了来源。方法不是全部必选的检查项，成片与观众理解仍需实际检验。

| 表达问题 | 放入哪一步 | 执行与边界 |
|---|---|---|
| 技术新鲜却没有意思 | 表达目标、资源判断 | 先确认机制如何承担主题；技术无法服务目标时换手段 |
| 表演机械或不可控 | 调度与表演 | 锁必要边界，以真实任务引出行为；实拍的可控变化不等于生成随机性 |
| 动作失重 | 动作与接触设计 | 保留阻力、受力、恢复与后果；失误仅在需要风险或脆弱感时使用 |
| 机位只在记录 | 摄影设计 | 确定观看者身份、信息范围与距离；固定机位也能承担关系 |
| 反应像提前表演 | 声音与剪辑 | 核对刺激、接收、反应顺序；反应余量服务感受，不统一加慢镜 |
| 事实不支持原提案 | 事实锁与验收 | 让反证改变判断；涉及锁定剧情或主张调整时回到授权范围 |
| 直接命令“自然” | 条件与调度 | 以道具、任务和空间引出动作，保留原因与后果 |
| 隐喻只有符号 | 表达映射与跨部门衔接 | 让抽象关系与载体共享结构，通过行为、构图或声画关系被感到 |

## 可追溯例证

- [Sinéad McDevitt《The Ocean》原访谈](https://directorsnotes.com/2019/09/20/sinead-mcdevitt-the-ocean/)与[Péter Vácz《Dear John》原访谈](https://directorsnotes.com/2016/07/28/peter-vacz-dear-john/)分别支持关系发展与画面变化、抽象感受与身体变化的对应。二者支持隐喻设计，不证明商业效果。共同触发是可选实施方式，不能推导所有运镜必须晚于动作。
- [Dan Attias原访谈](https://www.dga.org/craft/dgaq/issues/1803-summer-2018/dga-interview-dan-attias)与[Mary Lou Belli导演技巧](https://www.dga.org/events/2022/may2022/sp_directorsauthorsevent-0322)支持目标、道具与调度条件的关系。
- [Todd Haynes《May December》问答](https://www.dga.org/events/2024/january2024/maydecember_qna_1123)支持观察式机位与镜面观看关系；不支持“直视镜头必然高级”等固定等式。
- [Anu Valia《We Strangers》问答](https://www.dga.org/events/2025/october2025/westrangers_qna_0925)支持剪辑对反应时序的影响。

上述执行表是整理者的归纳，非导演逐字指令。已有隐喻原创例见 [expression-design.md](expression-design.md)，摄影实施见 [blocking-camera.md](blocking-camera.md)，避免把单个案例固化为每条片的剧情。
