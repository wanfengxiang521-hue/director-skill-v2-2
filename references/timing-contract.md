# 多轨时长合同

## 核心判断

提示词字数不等于时长。静态人物设定、场景、光线、构图、连续性和禁止项可以并行约束同一时刻；只有必须按顺序发生的事件、必须听完的声音和不可并行的转场增加最低时长。

## 五类负载

- `actor_track`：触发、评估、抵抗、策略行动、泄漏、后果等必须串行的表演状态变化。
- `dialogue_track`：成片必须听完的台词/旁白，加自然停顿、呼吸和句后反应。
- `camera_track`：摄影机启动、运动、停稳和终点停留。
- `sound_track`：必须同步完成的音效、声音桥、音乐节点或设计静默。
- `serial_transitions`：不能与四条轨道并行的进出场、跨地点、接触、复杂道具状态变化或剪辑过渡。

最低可执行时长：

```text
T_min = max(actor_track, dialogue_track, camera_track, sound_track) + serial_transitions
```

镜头计划时长必须满足 `planned_duration >= T_min`，并给生成起尾不稳定留出独立取材余量；取材余量不计入成片时长。

## 计算步骤

1. 把动作拆成状态变化，标出哪些能并行、哪些必须等待前一步完成。
2. 台词只计算最终需要听见的内容。优先使用真实试读；没有试读时给区间并标记待验证，不把统一“汉字/秒”当定律。
3. 摄影机运动若与人物动作同步，取较长轨道；若必须等人物动作完成后才启动，则计入串行事件。
4. 音效可以作为动作时钟；声音桥可跨切镜并与画面并行。
5. 计算 `T_min` 后检查终点是否至少可读一个节拍；不可读则增加停留或改变设计。
6. 对所有镜头求和，与总时长对账；不能靠加速台词、删掉反应或无意义慢动作硬凑。

## 成片镜头与生成单元

- 一个成片镜头可以由多个生成单元拼成，例如复杂接触的接近、接触结果分开生成。
- 一个稳定生成单元可以供剪辑取多个片段，但前提是内部动作连续且可裁切。
- 切镜数量、生成任务数量和表演节拍数量是三种不同计数，必须分别记录。

## 超载修复顺序

1. 删除不承担戏剧功能的动作、运镜或声音装饰。
2. 把能后期完成的精确文字、复杂声音或包装细节移到后期。
3. 把复杂动作拆成多个生成单元，但保持同一剧情事件。
4. 把长台词放到倾听镜头、画外音或跨镜声音桥，不改变台词含义。
5. 调整镜头时长并从其他镜头回收时间。
6. 若仍不可执行，报告剧本与总时长的物理冲突；不得偷偷删剧情。

## 输出字段

```yaml
timing:
  actor_track: {seconds: 0.0, serial_events: []}
  dialogue_track: {seconds: 0.0, evidence: "measured|estimated", pauses: []}
  camera_track: {seconds: 0.0, phases: []}
  sound_track: {seconds: 0.0, sync_events: []}
  serial_transitions: {seconds: 0.0, events: []}
  T_min: 0.0
  planned_duration: 0.0
  generation_handle: 0.0
  verdict: executable|revise|blocked
```
