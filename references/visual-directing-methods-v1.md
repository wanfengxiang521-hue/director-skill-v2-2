# 视觉导演方法 V1

只在方法与表达问题匹配时使用。以下为具体实施路径，不是全部导演任务的硬门槛。比较型方法建立可辨基线、变化和终态；保持构图或声音主导的方法按自身声画关系验收。不得把导演作品的表面风格当作方法。

## 选择顺序

1. 先定义观众状态变化和表达问题。
2. 选择一个主要方法。
3. 只有主要方法无法承担次要信息时，才增加一个辅助方法。
4. 检查资源依赖和误用边界。
5. 把方法落实到每拍 `START → MOTION → END`，否则不算采用。

### 用空间几何承载抽象关系变化

- 表达问题：阶层、亲密、权力、孤立或归属只靠台词说明，画面不能独立传达。
- 核心原则：先给关系指定空间变量，再由人物行动或观看位置使它可读。变量包括高度、距离、入口、路线、遮挡、面向和最终群体形状；实际空间与观众可见空间分别说明。
- 可执行决定：开场给出清楚基线；每次移动至少改变一种关系；结尾用新空间终态完成判断。
- 调度与空间：身体受建筑限制与观看受构图限制是两种不同路径，选定一种并保持物理一致；道具承担可说明的关系。
- 摄影机触发、路径与终点：决定观众需要掌握多少地理；人物跨界、观看权转移或遮挡揭示均可触发移动，停在关系最清楚的位置。固定构图能够承担关系时保持机位。
- 光线、声音与剪辑：用光区与声场区分真实空间；剪辑保护观众刚学会的地理，除非空间破坏本身就是视点变化。
- 适用条件：建筑会改变行为，或物理距离与情感关系存在戏剧矛盾。
- 容易误用：只放楼梯、镜子和门框制造“电影感”，人物权力、知识和欲望没有变化。

### 把抽象价值翻译为物理动词

- 表达问题：“自由、宽广、能力、掌控、治愈”等价值停留在广告语言，画面只有氛围或产品陈列。
- 核心原则：把核心价值改写成一个身体和环境都能执行的动词，让产品或命题成为动作因果。
- 可执行决定：采用动作因果路径时建立身体基线、触发与后果；选择必要的表演、空间、摄影或光声承担动词，其他部分可保持稳定；终态可与起态比较。
- 调度与空间：人物先是句子主语，产品或道具是促成动作的工具；空间出现可测量的压缩、扩展、跨越、恢复或解除规则。
- 摄影机触发、路径与终点：需要跟随动作揭示后果时，在触发后改变观察距离或路径；若摄影承担预示或主观感受，明确其先行理由。终框选择能完成本镜表达的人物、物体或空间关系。
- 光线、声音与剪辑：声音可作为触发；同步变化用于强调因果，提前或异步变化用于预示、反差时说明其作用。无需所有部门都发生变化。
- 适用条件：主张具有真实可见的使用因果，价值能准确翻译为一个主要动作。
- 容易误用：先设计通用奇观，再把任意产品放在旁边；把隐喻情绪当作功效证明。

### 建立视觉规则，再用偏差或有限变量推进

- 表达问题：循环、程序化或超现实画面虽醒目却没有因果，观众不知道变化为何重要。
- 核心原则：先让观众学会可预测规则，然后一次只改变少量变量；偏差必须改变状态、信息或风险。
- 可执行决定：至少一次清楚基线和一次重复确认；每次回到规则时增加或移除一个变量；关键偏差后改变速度、构图或空间终态。
- 调度与空间：重复路线、例行动作、人工媒介规则或任务步骤均可作基线；变量必须能被当场比较。
- 摄影机触发、路径与终点：基线阶段重复路径；偏差发生时才离开原路径或改变机距；终点显示规则被掌握、打破或解除。
- 光线、声音与剪辑：重复声音和稳定光线帮助学习规则；节奏、阴影、色彩或声场只在偏差时改变。
- 适用条件：内容存在可复现动作、空间几何或人工世界规则。
- 容易误用：复制、循环或一镜只展示技术，没有升级后果；规则尚未学会就被无序打破。

### 前景吸引注意，背景推进第二叙事

- 表达问题：需要同时表现“观众被什么吸引”和“吸引期间忽略什么”，交叉剪辑会替观众做选择。
- 核心原则：让一个清楚的前景动作持续占据注意力，同时让第二条因果链在可读背景中累积；观看遗漏本身成为主题。
- 可执行决定：先建立前景吸引物；背景事件分阶段进入并提高不可忽视程度；最后重新分配画面中心。
- 调度与空间：两条事件线都能独立读懂，并在纵深、方向或节奏上形成明确层级。
- 摄影机触发、路径与终点：宽景或持续移动同时保存两层；跟随前景但不裁掉背景；终点通过环绕、散开、反转或前景退出让背景成为主叙事。
- 光线、声音与剪辑：前景可由音乐或编舞锁定，背景异步进入；关键声音断点迫使观众重新分配注意力。
- 适用条件：主题涉及注意、遮蔽、共谋、表象与现实的冲突，并具备精确排练条件。
- 容易误用：背景堆满事件、符号和群众，却没有进入顺序与观看层级，只制造混乱。

### 重复同一路径，用有限变量表达时间与情绪

- 表达问题：关系和时间变化细微，新增剧情或解释台词会破坏克制。
- 核心原则：固定一条观众能记住的路线或摄影轨迹，只改变经过者、速度、距离、动作、停留或最后留下的人。
- 可执行决定：第一次完整教会路线；后续保留足够相似性；每次只突出一到两个差异；最后用缺席、拥挤、反向或尺度跃迁完成意义。
- 调度与空间：窄走廊、街区环线或自然路线均可使用；人物表演差异必须比布景风格更重要。
- 摄影机触发、路径与终点：摄影机可重复同一路径作为时间网格，也可逐次退让给更大环境；终点能与第一次直接比较。
- 光线、声音与剪辑：音乐副歌、脚步、环境声或稳定日光确认重复；时长和声场的细微差异负责情绪变化。
- 适用条件：内容受例行、记忆、季节、关系累积或尺度变化驱动。
- 容易误用：重复只有形式，变量没有情感或信息后果；漂亮路径取代人物变化。

## 通用验收

- 观众能否在第一次出现时学会基线？
- 每次变化是否只增加必要变量？
- 方法是否改变人物、信息、关系或风险？
- 摄影机的移动或保持是否服务观看关系，并有明确终框？
- 静音后留下什么、失去什么；有意由声音承担的意义是否在完整声画中成立？
- 去掉昂贵资源后，导演原则是否仍能成立？
